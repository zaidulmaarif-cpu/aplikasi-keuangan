# Dark Mode Financial Tracker App

Aplikasi pencatatan keuangan pribadi sederhana dengan antarmuka **Dark Mode** modern. Dibuat menggunakan HTML5, Tailwind CSS, JavaScript Vanilla, dan Chart.js.

## Fitur Utama
- **Dark Mode Default:** Tampilan nyaman di mata dengan palet warna Slate/Dark Gray.
- **Pencatatan Pemasukan & Pengeluaran:** Tambah dan hapus riwayat transaksi secara real-time.
- **Ringkasan Otomatis:** Menghitung total saldo, pemasukan, dan pengeluaran secara parsial.
- **Grafik Interaktif:** Visualisasi persentase pemasukan vs pengeluaran menggunakan Chart.js.
- **Local Storage:** Data transaksi tersimpan aman di browser tanpa memerlukan database external.
- **Responsive Web Design:** Optimal diakses melalui perangkat seluler maupun desktop.
